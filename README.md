# MIDS241-Weight-Checkin
Weigh-in Frequency Causal Study for MIDS 241

## GitHub Pages

This repository is configured for GitHub Pages deployment. The landing page is available at the root of the repository as `index.html`.

### Enabling GitHub Pages

To enable GitHub Pages for this repository:

1. Go to the repository's **Settings** page
2. Navigate to **Pages** in the left sidebar
3. Under **Source**, select the branch you want to deploy (e.g., `main` or `copilot/add-github-page-landing`)
4. Select **/ (root)** as the folder
5. Click **Save**

Your site will be published at: `https://uc-berkeley-i-school.github.io/MIDS241-Weight-Checkin/`

### Customizing the Landing Page

You can customize the landing page by editing the `index.html` file in the root directory. The page includes:

- Modern, responsive design
- Project information and description
- Research focus areas
- Links to resources

### Local Development

To test the page locally, run a simple HTTP server:

```bash
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080/index.html` in your browser.
